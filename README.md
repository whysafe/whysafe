## Обо мне

Начинал с сайтов и Telegram-ботов на заказ, потом ушёл глубже: бэкенд и базы данных, Android, игры на Unity, Linux и системное программирование вплоть до ассемблера. Мне нравится, когда код понятен и проверен, поэтому почти у каждого проекта здесь есть тесты, CI на GitHub Actions и README с инструкцией запуска.

- 🌐 Сайты, лендинги и интернет-магазины с уникальным дизайном
- 🤖 Telegram-боты: запись, магазины, поддержка, напоминания
- ⚙️ Бэкенд и API на Python, Java, Go и C#, базы PostgreSQL и MySQL
- 📱 Android на Kotlin и Jetpack Compose, iOS на Swift
- 🎮 Игры на Unity и HTML5, публикация в Яндекс Играх
- 🐧 Linux: настройка серверов, Docker, Bash, утилиты на C, C++ и Assembly
